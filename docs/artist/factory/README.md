# Factory visual reference PNGs

These 66 PNG files are the minimal visual set used by the Sport night preview and editable component map. They were extracted byte-for-byte from the owner's verified stock Launcher backup:

`f92b2c2c627b0d61a1bbf7f750f5b6efea808fded396b67c2ce2c2c1215db473`

`../factory.mjs` records the exact pixel dimensions, byte lengths and SHA-256 values. This directory contains no executable Launcher, boot partition, fonts, vehicle identity, credentials, or personal artwork.

The manufacturer's visual assets remain the work of their respective rights holders; the repository's MIT license for application code does not grant rights to the manufacturer's artwork. The files are included as the factory visual reference requested by the vehicle owner, separately from application code and user projects.

The browser combines these PNGs with simulated values and system text. It is a design preview, not a live dashboard, factory screenshot, or Qt runtime emulator. Some warning symbols are drawn in code. Check the final layout, masks, readability, and resource budget in Studio before vehicle installation.
