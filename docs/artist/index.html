รูปไหนคือส่วนไหน

กดการ์ดเพื่อเลือกส่วนบนจอ เส้นประจะแสดงบริเวณที่เกี่ยวข้อง ดูชื่อ PNG และขนาดของทุกไฟล์ได้ในแผงขวา ภาพพื้น ตัวเลข และแถบระดับเป็นคนละชั้นกัน

จากนักวาดสู่หน้าปัดจริง

  1. วาดจาก template และเก็บ layer ต้นฉบับในโปรแกรมวาด
  2. นำ PNG มาเลือกแยกชิ้น ปรับสีและความโปร่ง เทียบกับข้อมูลตัวอย่าง
  3. ถ้ามี template จริง ให้โหลดโฟลเดอร์ในเครื่องเพื่อใช้ mask จริง ชิ้นที่ยังไม่โหลดจะใช้ PNG โรงงาน
  4. กด บันทึกโปรเจกต์ ส่ง JSON ที่แนบภาพให้เจ้าของรถ เปิดด้วย Studio ได้
  5. ส่งออกชิ้นภาพ เป็น PNG/preview/project/palette ใน ZIP สำหรับตรวจงาน ไม่ใช่ไฟล์ติดตั้งรถ
  6. เจ้าของรถใช้สำเนา firmware ที่ตรวจ SHA ใน Studio ก่อนสร้างไฟล์จริงและติดตั้ง

ตัวอย่างไม่ใช่ Qt emulator ใช้ PNG โรงงานเป็นฐาน ส่วนตัวอักษรระบบ ตำแหน่งและค่าข้อมูลยังเป็นการจำลอง ภาพ JPG/GIF จะใช้เฟรมภาพนิ่งแรก การย่อ/ครอปใน browser อาจต่างจากตัวแปลงจริงเล็กน้อย

การลดจำนวนสีและพื้นที่ QRC จะตรวจใน Studio การเปิดงานเก่าที่เคยตั้งลดสีจะเก็บค่านั้นไว้ แต่ Artist Mode พรีวิวแบบสีเต็ม

JSON ที่ส่งออกแนบภาพ/PNG template ที่คุณโหลดไว้ ไม่มีการบันทึกอัตโนมัติหรืออัปโหลด อย่าปิดแท็บก่อนบันทึกงาน
